## 1. 遊戲介紹

疆域骰戰是一款兩人連線、回合制的擲骰征服網頁遊戲，手機、平板、電腦都能玩，不用下載也不用註冊。

- **一句話**：選一個國家，在隨機生成的地圖上擴張領土，靠擲骰攻下對手首都。
- **對局流程**：建立房間 → 分享 5 碼房號或連結 → 兩人各選國家 → 各選一塊地當首都 → 輪流行動，直到一方滅國。
- **每回合只能做一件事**：開墾空地、進攻敵地、或遷都。
- **開墾**：陸地相連的空地一定成功；跨海要擲 6 面骰，擲出 1 或 6 失敗。
- **進攻**：擲 12 面骰，結果分大成功、成功、失敗、大失敗。成功會在敵地留下「佔領標記」，一般領土 2 層就被拿下，首都要 3 層。
- **滅國**：首都被攻下 2 次。第一次失守後可以免費另立首都。
- **地圖**：大陸、群島、混合三種，每局用亂數種子生成，約 30 多個區域。
- **國家**：日本、英國、美國、義大利、法國、德國、蘇聯，各有一個技能（見第 4 節「國家」表）。
- **一局時間**：大約 40 到 70 回合。

**整體調性**：「作戰室」。地圖畫成攤開在桌上的羊皮紙，旁邊是深色的指揮面板。目前是暗色主題，沒有亮色版。

**時代與題材**：7 個國家對應二戰時期的列強，但遊戲是輕鬆的桌遊風，不寫實、不血腥。

**名稱與標語**：遊戲名「疆域骰戰」，副標「兩人連線 · 擲骰定疆界」，首頁大標「畫下國界，擲出天下」。左上角的 logo 是一個略為傾斜的黃銅色方塊，裡面寫「疆」字。

## 2. 畫面清單

整個網站只有一頁，依遊戲階段切換成 4 個畫面，加上 2 個浮層。每個畫面上方都有共用頂欄：logo、遊戲名、連線狀態膠囊（綠點「已連線」或紅點「斷線」）。

| 畫面 | 什麼時候出現 | 上面有什麼 |
|---|---|---|
| 入口 | 剛打開網站 | 左邊：大標、遊戲說明、7 國卡片牆。右邊：名字輸入框、「建立房間」主按鈕、「或」分隔線、5 碼房號輸入框與「加入」按鈕 |
| 大廳 | 進房後、開戰前 | 大字房號、邀請連結與複製鈕、地圖類型三段切換（大陸／群島／混合）與「換一張地圖」、地圖預覽、兩個座位（玩家名、在線狀態、7 國選擇格、技能說明）、「開戰」按鈕 |
| 對局 | 開戰後 | 左邊：地圖（3:2 畫布）、上方回合橫幅。右邊面板由上而下：回合卡（國家色旗條、技能就緒狀態）、行動按鈕列（開墾／進攻／遷都／技能／結束回合）、區域資訊卡、勝率條、雙方名單（領土數長條、首都命數）、戰報、規則摺疊區 |
| 結算 | 有人滅國 | 蓋在地圖上的半透明遮罩，中間一個框寫「某國 統一天下」與「再來一局」 |
| 擲骰浮層 | 每次擲骰 | 全螢幕模糊遮罩，中間一張卡：誰擲的、動作標題、一顆大骰子（滾動後停在點數）、12 格結果色條、結果大字（大成功／成功／失敗／大失敗） |
| 提示訊息 | 操作失敗或房主離線 | 底部置中的紅色吐司；房主離線時頂部有一條黃褐色橫幅 |

**三種裝置的版面**

- **電腦（寬於 1080px）**：地圖在左，面板 360px 寬在右，地圖跟著捲動固定在畫面上。
- **平板（820–1080px）**：同上，面板縮成 310px。
- **手機與直立平板（窄於 820px）**：地圖在上、面板在下，行動按鈕列固定在螢幕底部。手機上點地圖要點兩下確認，電腦點一下即可。

## 3. 現有視覺風格

目前的顏色都集中在 `app/globals.css` 開頭的變數裡，改這裡就能改整站配色。可以當作起點，也可以整套換掉。

**介面色票**

| 變數 | 色碼 | 用在哪裡 |
|---|---|---|
| `--ink` | #141a1f | 網頁底色、輸入框底 |
| `--panel` | #1d252c | 卡片底色 |
| `--panel2` | #252f37 | 一般按鈕底色 |
| `--line` | #36424c | 邊框、分隔線 |
| `--text` | #ece4cf | 主要文字（偏米白） |
| `--muted` | #9d9a8c | 次要文字、標籤 |
| `--parch` | #e8dcb8 | 羊皮紙色（骰子面） |
| `--brass` | #d4a94e | 品牌主色：logo、主按鈕、房號、選中狀態 |

**擲骰結果色**（骰子、勝率條、結果大字共用）

| 結果 | 變數 | 色碼 |
|---|---|---|
| 大成功 | `--crit` | #f2c24f |
| 成功 | `--good` | #6cbf7a |
| 失敗 | `--fail` | #8d969c |
| 大失敗 | `--bad` | #e0584e |

**字體**

- 標題與國名：Noto Serif TC，粗體 900，帶一點字距。從 Google Fonts 外載。
- 內文：系統字（Windows 微軟正黑體、Mac／iOS 蘋方），不外載。15px。
- 數字與房號：IBM Plex Mono，從 Google Fonts 外載。
- 中文字體外載很重，標題字體請只選一個。

**地圖畫風**（畫在 canvas 上，寫在 `components/MapCanvas.js`）

- 海：近岸淺藍綠 rgb(126,176,194) 漸層到深海 rgb(30,62,92)，上面有淡淡的經緯線。
- 陸地：羊皮紙色，從 rgb(238,227,192) 到 rgb(206,190,146) 的雜訊紋理；海岸線外一圈白色淺灘光暈。
- 領土：用國家色半透明塗滿，國界用國家色加深的粗線。
- 海路：白色虛線，連接可以跨海的兩個區域。
- 左下角有「0 — 100 里」比例尺。

**形狀與質感**：圓角 6–8px（骰子與彈窗 12px），膠囊形標籤，卡片有 1px 邊框，幾乎不用陰影。地圖外框是深褐色的雙層邊，像裱框。

## 4. 需要設計的素材

最有感的兩件事是 **7 國的視覺識別** 與 **地圖上的狀態符號**，其他可以慢慢來。目前網站沒有用任何圖片，全部都是 CSS 與程式畫的。

### 4.1 國家

每國一個代表色，用在領土、國界、旗條、名單、骰子彈窗邊框。

| 國家 | 現在的顏色 | 技能 | 技能內容 |
|---|---|---|---|
| 日本 | #e06b86 櫻粉 | 天皇 | 每 2 回合可免費把首都遷到任一自有領土 |
| 英國 | #9a6ee0 紫 | 日不落 | 跨海作戰 +2；第一回合可開墾兩塊 |
| 美國 | #e8962f 橘 | 軍火商 | 進攻 +1；敵人攻美國 −1 |
| 義大利 | #4aa866 綠 | 美食家 | 進攻 −2；領土要 3 層標記才失守（首都 4 層）；每 3 回合可清一層標記 |
| 法國 | #3c8ce0 藍 | 馬奇諾防線 | 敵人從陸路攻首都或首都旁邊 −2 |
| 德國 | #8d9aa6 鐵灰 | 閃電戰 | 從乾淨的領土攻成功後可再攻一次 |
| 蘇聯 | #d2463c 紅 | 冬將軍 | 敵人拿下的蘇聯領土變焦土，2 回合不能用 |

**可以設計**：國徽或國家圖示（方形，小到 20px 還能辨認）、每國技能圖示、調整後的 7 個國家色。

**配色限制**

- 7 色要在羊皮紙底上彼此分得開。
- ⚠ **目前已經撞色，必須換**：
  - 蘇聯紅 #d2463c 與「大失敗」#e0584e 幾乎一樣，也跟「佔領標記」的紅衝突。
  - 德國灰 #8d9aa6 與「失敗」#8d969c 幾乎一樣。
- 日本粉、美國橘、蘇聯紅色相偏近；「焦土」的橘色徽章也和美國橘重複，請一併調整。

**圖像限制**：國徽請用抽象或中性的圖示，**不要使用納粹標誌**，也避開其他敏感的政治符號。

### 4.2 地圖上的狀態符號

現在都是程式畫的簡單圖形。

| 狀態 | 現在的樣子 |
|---|---|
| 首都 | 國家色五角星，黑邊 |
| 佔領標記 | 紅色斜線底紋＋一排小圓點（紅 = 已中、米白 = 還差幾層） |
| 焦土（蘇聯） | 深褐色點狀底紋＋橘色圓徽章寫「焦」 |
| 可選目標 | 白色呼吸光暈＋白邊 |
| 出兵地 | 金色虛線邊；選中後變實線 |
| 進攻路線 | 金色線（跨海時是虛線） |
| 區域名稱 | 深褐字、米色描邊，10.5px |

### 4.3 骰子

現在是羊皮紙色圓角方塊寫數字，右下角標 d6 或 d12，停下後變成結果色。可以設計 d6 與 d12 外型、滾動動畫、四種結果的演出（例如大成功的特效）。

### 4.4 其他可以做的

- [ ] Logo（現在是一個「疆」字方塊）
- [ ] 網站 favicon（瀏覽器分頁圖示，目前沒有）
- [ ] 分享預覽圖（貼連結到 LINE、Discord 時顯示的圖，1200×630，目前沒有）

- [ ] 勝利畫面的演出

優先順序：4.1、4.2 為必做；4.3 與 4.4 視時間選做。**亮色主題：不做。**

## 5. 限制與交付方式

交色碼、SVG、字體名稱最容易套用；設計稿用 Figma 或截圖標註都可以。

**設計時要注意**

- 最小寬度 360px 的手機也要能玩。地圖在手機上只有大約 360×240px，符號要在這個大小下看得清楚。
- 手指點的按鈕至少 44px 高。
- 地圖是程式即時生成的，每局形狀都不同，無法用一張畫好的地圖圖。可以設計的是色彩、紋理（可重複的小圖塊）、邊線樣式、符號。

**素材格式**

| 素材 | 建議格式 |
|---|---|
| 國徽、技能圖示、地圖符號、logo | SVG（單色或少色，可以用程式換色最好） |
| 紋理（羊皮紙、海浪） | 可重複拼接的 PNG，每張 200KB 以內 |
| 分享預覽圖 | PNG 或 JPG，1200×630 |
| favicon | SVG，或 512×512 PNG |
| 配色 | 色碼清單，對應上面的變數名稱 |
